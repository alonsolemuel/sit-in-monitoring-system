# 🖥️ Sit-In Monitoring System

**A web app for managing student sit-in sessions in college computer laboratories.**

Students can reserve a lab PC, check which PCs are available, view their sit-in history and send feedback. Admins can run sit-in sessions, manage students, post announcements, control lab and PC availability, and see usage reports.

## ✨ Features

### For students
- Register, log in and edit your profile
- See available labs, time slots and live PC status
- Reserve a PC and manage your reservations
- View your sit-in history and summary
- Submit feedback after a session
- Get notifications and announcements
- See the lab software list and a usage leaderboard

### For admins
- Dashboard with usage statistics
- Search, add, edit and remove students
- Start and end sit-in sessions, view active sit-ins and records
- Approve or reject reservations, turn reservations on or off
- Set lab availability and mark PCs under maintenance
- Manage lab software (add, edit, upload)
- Post announcements and review / flag feedback (with a profanity filter)
- Export records to CSV

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Backend | Python, Flask |
| Database | SQLite |
| Frontend | HTML (Jinja2 templates), CSS, JavaScript |

## 🚀 Getting Started

**Requirements:** Python 3.10+

```bash
git clone https://github.com/alonsolemuel/sit-in-monitoring-system.git
cd sit-in-monitoring-system/SITINMONITORINGSYSTEM
pip install -r requirements.txt
python App.py
```

Then open http://localhost:5000
